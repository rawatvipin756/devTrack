# DevTrack 🚀

DevTrack is a developer productivity dashboard designed to help developers organize their daily tasks, track progress, and stay focused on their development goals.

It provides a clean and intuitive interface to manage tasks and monitor productivity in one place.

## 🌐 Live Demo

[View Live Demo](https://dev-track-eta-tawny.vercel.app/)

## ✨ Features

- **Task Management:** Organize and manage daily development tasks.
- **Task Tracking:** Keep track of completed and pending tasks.
- **Productivity Dashboard:** Get an overview of total, completed, and pending tasks.
- **Task Status:** Track task progress efficiently.
- **Responsive UI:** Clean and responsive dashboard layout.
- **Modern Design:** Minimal and developer-friendly interface.

## 🛠️ Tech Stack

- HTML5
- Tailwind CSS
- JavaScript

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/rawatvipin756/devTrack.git
```

### 2. Navigate to the project directory

```bash
cd devTrack
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start Tailwind CSS

```bash
npm run dev
```

Open `index.html` in your browser to explore the application.
